# Дополнительные примеры C#

50 методов из предоставленного набора `examples-csharp-expanded`, объединённых
с каталогом `examples`. Каждый `.cs` содержит один метод без класса.

[`cases.json`](cases.json) сохраняет названия, категории, описание задачи,
заметки о графе и контрольные входы с ожидаемыми результатами. Viewer использует
этот каталог для поиска и выбора примеров. Приложение разбирает методы, но не
выполняет контрольные вызовы и не проверяет их результаты.

Категории охватывают линейный код, ветвления, выражения и выбор, базовые циклы,
ранние переходы, сочетания конструкций и вложенные циклы. Наличие примера в
списке означает, что он доступен для разбора AST, а не гарантирует полноту
поддержки всех конструкций текущими CFG/SSA.

Семь исходных примеров лежат на уровень выше. Одинаковые имена файлов
различаются путём (например, `01-sequence.cs` и `expanded/01-sequence.cs`).
