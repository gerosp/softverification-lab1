# Начальные примеры

Файлы содержат отдельные методы: для компиляции C# их нужно поместить в класс.
CLI и viewer добавляют служебный класс самостоятельно. Примеры предназначены для
разбора; приложение не компилирует и не исполняет пользовательский C#.

| Файл | Ожидаемые конструкции | Что пригодится при реализации SSA |
|---|---|---|
| `01-sequence.cs` | Объявления, бинарные выражения, повторное присваивание | Новая версия `y` после присваивания, без φ |
| `02-if-else.cs` | `if_statement`, две ветви, унарный минус | Слияние двух определений `result` перед `return` |
| `03-nested-if.cs` | Вложенные `if`, `else if`, ранний `return` | Слияния `result`; завершившаяся ветвь не идёт к следующему оператору |
| `04-while.cs` | Условие и тело `while`, счётчик и аккумулятор | Значения `i` и `total` на входе в цикл и на обратном ребре |
| `05-for.cs` | Инициализатор, условие, инкремент, вложенный `if` | Слияние `total` после условия и на следующей итерации |
| `06-do-while.cs` | Проверка после тела, `bool`, `&&`, `||` | Обратное ребро; отдельное моделирование короткого замыкания |
| `07-nested-loops.cs` | Вложенные циклы, `break`, `continue`, локальный `j` | Правильные цели переходов, отдельные области видимости и слияния |

Описание SSA здесь — ориентир для следующего этапа, не результат анализа программы.
